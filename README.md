# personal_dotfiles
Mine, you can use it if you want. Used with Labwc/fedora with tuned power manager and envycontrol for a dual laptop setup. Just copy the config files over to yours

sudo dnf install -y terra-release
sudo dnf config-manager --add-repo https://download.docker.com/linux/fedora/docker-ce.repo
